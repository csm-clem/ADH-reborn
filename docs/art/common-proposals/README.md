# Cartes communes — propositions

Cinq illustrations vectorielles autonomes, sans image embarquée ni filtre lourd. Cette planche propose une direction gravure musicale, cuivre mat, papier et encre pétrole. Elle ne remplace pas encore les illustrations en application. Les raretés supérieures gardent la priorité sur les effets métalliques et holographiques.

- `first-session` — **La première fait le jack** : Un objet sculptural, un premier signal solaire et un câble qui guide le regard.
- `opens-named` — **Enchanté, moi c’est…** : Six mécanismes et leurs signatures sonores : l’accordage devient une collection de voix.
- `diagram-check` — **Le manche a un sens** : Une carte architecturale avec boussole : comprendre l’instrument comme un territoire.
- `first-discovery` — **Il y a du monde sous les doigts** : Un herbier de positions lumineuses : découvrir les notes, faire pousser ses repères.
- `first-chain` — **Le fil du riff** : Un seul fil traverse la forme d’onde et rejoint le vinyle : continuité du geste et du phrasé.
