# Correctifs du prochain lab v0.39

Base : release live v0.38 vérifiée ; changements déjà publiés retirés du lot en attente. Aucun déploiement live demandé.

Réglages : séparateurs entre chaque groupe Aide/Sauvegardes, pas sous les titres. Boutons : orange #f8a744 vers rouge #e94647, survol orange vers bleu #202980 ; les apparences contrastées dédiées sont conservées.

Manche : centré lorsque le contenu tient, scrollbar uniquement en cas de débordement, recalcul au redimensionnement sans reconstruction complète de la page. La pastille d’une question Nommer est recadrée après rotation ; aucune révélation automatique pour Retrouver. La largeur minimale de 44 px par case sur les manches défilables est conservée.

Leçons longues : largeur disponible plutôt que bloc limité à 900 px ; hauteur de manche 240 px. La case 24 termine réellement l’instrument par un léger arrondi, sans fondu ni portion de case suivante, dans le moteur partagé.

Vérification locale : 228 tests Node réussis, candidat et ressources vérifiés ; contrôles navigateur de centrage, rotation, scrollbar, réglages, grandes introductions et six formats réussis. Les essais sur téléphones physiques restent nécessaires. Les liens CI et de livraison seront ajoutés à la roadmap après leur fin.

La proposition de roues ovales et de loupe reste un travail de conception : voir ../ux-navigation/NECK-24-MOBILE.md . Elle n’est pas implémentée dans ce lot.

## Limite de contraste de la palette demandée

Le fond orange #f8a744 donne un contraste d’environ 1,98:1 avec du texte blanc. La palette exacte demandée est conservée pour Atelier et Studio Nuit ; ces boutons ne sont donc pas annoncés conformes AA. Les thèmes Inclusif et Papier gardent leurs aplats contrastés. Les contrôles mesurent toujours les textes de l’interface dans tous les thèmes, et les boutons dans les thèmes contrastés ; les ratios des dégradés sont enregistrés séparément.
