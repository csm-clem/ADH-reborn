# DFT — 25 styles de cartes Succès

Livraison graphique du 29 octobre 2026 : cinq variantes PNG pour chacune des cinq raretés, cinq SVG sélectionnés et une galerie comparative portable.

| Rareté | Sélection |
|---|---|
| Commune | 01 — Cuivre sur vélin |
| Inhabituelle | 01 — Argent guilloché |
| Rare | 03 — Opale porcelaine |
| Épique | 04 — Graphite aurora |
| Légendaire | 05 — Reliquaire d’obsidienne |

Les Épiques et Légendaires portent un reflet dichroïque sur toute la face. La Légendaire est majoritairement noire, obsidienne et kintsugi doré.

Les SVG sont hybrides : cadre, surface, textes, boutons, progression et décors vectoriels éditables ; illustration seule conservée en PNG, masquée à sa fenêtre. Microtextures reconstruites, pas de promesse d’identité pixel par pixel. La galerie permet de comparer chaque choix PNG et SVG.

L’archive complète inclut les 25 PNG 1024×1536, les cinq SVG, les cinq planches comparatives, les références GitHub d’origine et les sources de création. Après extraction, ouvrir `index.html`.

Cette livraison est strictement graphique : aucune intégration des PNG/SVG dans l’application et aucun déploiement lab/live. Les progressions et dates affichées sont simulées pour présenter les finitions.
