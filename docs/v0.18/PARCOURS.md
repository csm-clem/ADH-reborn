# Parcours de référence — guitare six cordes standard, cases 0 à 4

Règle : accordage → famille isolée → mélange enrichi. Notes naturelles d’abord ; familles altérées ensuite. Chaque étape a une activité Nommer et une activité Retrouver. Toutes restent accessibles. Les règles sont partagées dans `curriculum-rules.js`.

## Micro-leçons et positions présentées

### Vos cordes à vide

Une ligne = une corde. La plus grosse est en bas. Touchez avant le sillet (la barre verticale épaisse).

- **E2** : corde 6, à vide.
- **A2** : corde 5, à vide.
- **D3** : corde 4, à vide.
- **G3** : corde 3, à vide.
- **B3** : corde 2, à vide.
- **E4** : corde 1, à vide.

### Tous les E

E2, E3, E4 portent le même nom. Le chiffre indique la hauteur : plus il monte, plus le son est aigu.

- **E2** : corde 6, à vide.
- **E3** : corde 4, case 2.
- **E4** : corde 1, à vide.

### Tous les A

Cherchez les A d’une corde à l’autre. Le nom reste le même quand le son monte.

- **A2** : corde 5, à vide.
- **A3** : corde 3, case 2.

### Tous les D

Retenez les places des D. Touchez-les dans l’ordre que vous voulez.

- **D3** : corde 4, à vide.
- **D4** : corde 2, case 3.

### Tous les G

Associez chaque G à sa corde. Commencez par le plus grave, puis essayez les autres.

- **G2** : corde 6, case 3.
- **G3** : corde 3, à vide.
- **G4** : corde 1, case 3.

### Tous les B

Observez où se trouvent B2, B3. Essayez de reconnaître leur dessin.

- **B2** : corde 5, case 2.
- **B3** : corde 3, case 4.
- **B3** : corde 2, à vide.

### Tous les F

La famille F rejoint votre carte. Comparez ses emplacements avant de les toucher.

- **F2** : corde 6, case 1.
- **F3** : corde 4, case 3.
- **F4** : corde 1, case 1.

### Tous les C

Tous ces points sont des C. Écoutez-les : un même nom peut sonner à plusieurs hauteurs.

- **C3** : corde 5, case 3.
- **C4** : corde 2, case 1.

### Tous les F♯

Découvrez les F♯. Le signe ♯ se lit « dièse ». Retrouvez le nom entier sur le manche.

- **F♯2** : corde 6, case 2.
- **F♯3** : corde 4, case 4.
- **F♯4** : corde 1, case 2.

### Tous les C♯

Une nouvelle famille : C♯. Cherchez son dessin parmi les cordes.

- **C♯3** : corde 5, case 4.
- **C♯4** : corde 2, case 2.

### Tous les G♯

Repérez les G♯, puis essayez-les dans un autre ordre.

- **G♯2** : corde 6, case 4.
- **G♯3** : corde 3, case 1.
- **G♯4** : corde 1, case 4.

### Tous les D♯

Reliez le nom D♯ à chacun de ses points. Les chiffres distinguent leurs hauteurs.

- **D♯3** : corde 4, case 1.
- **D♯4** : corde 2, case 4.

### Tous les A♯

Rassemblez les A♯ : même nom, plusieurs repères à reconnaître.

- **A♯2** : corde 5, case 1.
- **A♯3** : corde 3, case 3.

## Règles de présentation

Les exemples explicatifs montrent les positions nommées. La découverte interactive ne montre que les positions déjà trouvées, en vert avec leur nom. Son bouton de pratique devient actif lorsque toutes les positions de la famille ont été touchées. Les questions ne donnent pas leur réponse : un point neutre pour nommer, aucun point cible préaffiché pour retrouver. Les mélanges reprennent toutes les positions déjà introduites ; au moins 20 % des questions portent sur la famille qui vient d’être ajoutée.

Dans un accordage exotique, les familles naturelles présentes à vide viennent d’abord, dans l’ordre de l’accordage du grave vers l’aigu. Les autres naturelles suivent l’ordre F, C, G, D, A, E, B en sautant celles déjà introduites. Après les naturelles, les familles altérées présentes à vide passent avant les autres, puis l’ordre restant est F♯, C♯, G♯, D♯, A♯. Les familles absentes de la zone sont ignorées. Les hauteurs et l’accordage réel ne sont jamais modifiés.

Les futures zones 4–8, 7–11 et 12–16 utilisent le même générateur, testé pour ne proposer aucune position hors de leur zone. Elles ne sont pas encore proposées dans l’interface. Le rappel de l’accordage est inclus dans la zone 0–4 ; les autres zones commencent directement par les familles.
