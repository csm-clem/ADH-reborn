# Micro-leçons v0.3 — document de relecture

État de référence : commit `93bae29`, 13 octobre 2026. Les contenus sont extraits des fonctions `lessons` et `microCourse` de `core.js`. Chaque capture reproduit la carte `.briefing` réellement affichée par l’application, en thème clair et notation internationale, dans une fenêtre Chromium de 1100 × 1100 px ; la carte est capturée dans son intégralité. L’affichage mobile peut différer.

- [Word modifiable](../downloads/adh-v0.3-micro-lecons.docx) : les 35 leçons guitare 6 cordes et les 41 leçons guitare 7 cordes, dans leur ordre, avec textes éditables et capture sur chaque fiche.
- [PDF](../downloads/adh-v0.3-micro-lecons.pdf) : même contenu, 77 pages dont la page d’introduction.
- [HTML autonome](../downloads/adh-v0.3-micro-lecons.html) : toutes les configurations actuelles, soit 210 leçons : guitare 6/7/8 cordes et basse 4/5/6 cordes. Sélection de l’instrument, textes modifiables, remarques, export/import JSON et impression du parcours choisi. Télécharger le fichier et l’ouvrir dans un navigateur.

Les accordages utilisés sont les standards fournis par l’application. Les variantes Do Ré Mi et les accordages personnalisés ne sont pas dupliqués dans ces documents. Aucun texte de l’application n’a été corrigé pendant cette extraction.

## Donner un retour

Préciser l’identifiant, par exemple `guitar6 / s0-first`, puis le problème, le texte proposé et le changement visuel souhaité. Dans Word/LibreOffice, modifier le texte ou ajouter un commentaire. Dans le HTML, télécharger les retours avant de fermer le fichier : les modifications ne sont pas enregistrées automatiquement. Le JSON exporté permet de reprendre la relecture ou de transmettre les propositions.

## Vérifications

76 fiches et 76 images présentes dans Word ; identifiants des 76 leçons présents dans le PDF ; 210 articles dans le HTML. Sélection du parcours et export/import des remarques testés dans Chromium. Les captures ont été réalisées sans erreurs JavaScript. L’application et son ZIP v0.3 restent inchangés.
