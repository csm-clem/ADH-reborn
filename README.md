# DFT — collection graphique PNG

Livraison des 59 illustrations de cartes Succès, le 29 octobre 2026.

- 5 Communes
- 11 Inhabituelles
- 28 Rares, dont 13 musicales
- 12 Épiques
- 3 Légendaires

Toutes les illustrations sont en 1536 × 1024. Le ZIP inclut une galerie locale `index.html` et le manifeste des illustrations.

Cette branche sert uniquement à livrer les fichiers graphiques. Elle ne remplace aucune version de l’application et ne déclenche aucun déploiement DFT. L’intégration des PNG reste une étape ultérieure à autoriser explicitement.

Le ZIP original dépasse la limite GitHub de 100 Mo par fichier Git. Ses fragments binaires sont conservés ici et un workflow les réassemble, contrôle chaque empreinte et publie le ZIP complet en pièce jointe d’une prépublication graphique distincte des releases de l’application.
